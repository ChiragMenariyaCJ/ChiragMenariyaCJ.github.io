# 📋 Cheatsheets

Short, task-focused references for commands and syntax that are easy to forget. These pages are memory aids, not substitutes for understanding the command or protocol.

!!! warning "Check before you run"
    Confirm the target, current directory, privileges, side effects, and rollback. Use assessment commands only in an environment where you have permission to work.

## Command journal template

```text
Date/time and timezone:
Host / account:
Purpose:
Command:
Expected effect:
Actual result:

```

When a command is unfamiliar, read its local help and manual first. Flags and defaults can differ by version and platform.
