## My working loop

<div class="portfolio-process" markdown>

<div class="portfolio-process__step" markdown>
<span class="portfolio-process__number">01</span>
### Scope
Start with authorisation, context, and a clear question worth answering.
</div>

<div class="portfolio-process__step" markdown>
<span class="portfolio-process__number">02</span>
### Map
Understand the architecture, trust boundaries, authentication, data flow, and likely failure points.
</div>

<div class="portfolio-process__step" markdown>
<span class="portfolio-process__number">03</span>
### Build / test
Implement carefully, then test assumptions in a controlled environment with reproducible evidence.
</div>

<div class="portfolio-process__step" markdown>
<span class="portfolio-process__number">04</span>
### Explain
Turn the result into practical documentation, prioritised findings, and a path toward remediation.
</div>
