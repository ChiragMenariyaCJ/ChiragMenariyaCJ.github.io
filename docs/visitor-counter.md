This is an approximate visit signal shared with the counter on the home page.
It counts at most one visit per browser every 24 hours and is stored outside
the generated GitHub Pages files, so normal site builds do not reset it.

To reset the active counter, use the owner command documented in the
[repository README](https://github.com/ChiragMenariyaCJ/ChiragMenariyaCJ.github.io#reset-the-counter-owner-command).
